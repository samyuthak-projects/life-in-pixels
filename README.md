#  Life in Pixels

A modern desktop mood tracking app built with Python and CustomTkinter.  
Users can log in, record daily moods, and visualise their emotional journey as a pixel-style grid.

---

## Features

- 🔐 User authentication system (login & register)
- 💾 Persistent data storage using JSON
- 🌈 Daily mood tracking system
- 🟩 Pixel-style mood visualisation grid
- 🔥 Streak tracking system
- 🎨 Modern UI built with CustomTkinter
- 🌙 Light/Dark mode toggle
- 🧠 Personalised dashboard per user

---

## How it works

- Each user creates an account or logs in
- They select a mood for the day
- The mood is saved locally
- Each mood is displayed as a coloured “pixel”
- Over time, a visual pattern of moods is formed
